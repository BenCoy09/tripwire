Does the code keep the promises the paperwork made?

A building is sold as tokens. The legal terms promise investors four things. Tripwire attacks the token to see which promises the code really keeps.

Your terms are tested against the sample token, ART.

The same attacks run on a real EVM chain in the project’s repository (run.mjs): the deployed token held 1 of 4 promises, the fixed token 4 of 4, with transaction hashes in the report files. This page replays them on a simulated model of the token. Tripwire tests whether code enforces the terms. It does not judge whether the terms are legally sufficient and is not legal advice.
