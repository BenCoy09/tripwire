Hashed

Re-runnable

Testnet anchor

Post the report hash in a transaction. Tripwire reads it back and checks the exact hash is inside. It proves the report existed at that block time and hasn’t been edited since. It does not prove the report is right, and it doesn’t come from the issuer.
